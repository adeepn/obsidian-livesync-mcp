# Артефакты S3

`preparation-pytest.txt` — полный pytest при подготовке Task 10.
`preparation-offline.txt` — сценарий helper на FakeObjectStorage (LEGACY),
включая ожидаемые отрицательные проверки: повторная запись, несовпадение байтов,
пустой набор файлов. FAIL в этом файле — ожидаемые результаты этих проверок.
Это не результаты живой приёмки. Логи live-команд, скриншоты и `result.txt`
добавляются пользователем и контроллером после выполнения чек-листа.
